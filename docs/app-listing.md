## 应用介绍（详情页长文案）

SHISON 加热器是一款通过蓝牙（BLE）直连控制 SHISON 加热棒的鸿蒙原生应用。无需联网、无需账号、无需云端，打开手机即可完成全部操作。

主要功能：
- 蓝牙扫描附近设备，自动识别 SHISON 加热器（名称 SICN-HEATER-* 或广播含 FFF0 服务）；
- 实时显示当前温度与工作状态（降温 / 恒温 / 加热 / 超温 / 离水断电 / 探头故障）；
- 设置目标温度：滑块、加减步进、快捷档位，支持 ℃ / ℉ 切换；
- 查看 24 小时 / 60 分钟历史温度曲线，自动统计最低、最高与平均温度；
- 设备库：连接过的加热器自动记忆，支持多设备与「自动连接」，启动即回连；
- 三类报警（超温保护 / 离水断电 / 探头故障）触发独立报警页，脉冲动画加震动提醒；
- 工作模式用颜色区分，异常状态一眼可见；
- 纯 ArkTS 实现，无第三方 SDK、无广告、无联网，诊断日志仅存于本机沙箱。

使用说明：开启手机蓝牙并靠近加热器（建议 1 米内），首次使用授予「附近设备 / 蓝牙」权限，在设备选择弹窗中点选加热器即可连接。BLE 功能需要真机，模拟器不可用。

隐私说明：本应用不联网、不收集个人信息、不上传数据，仅申请蓝牙与震动权限。详见应用内说明与《隐私政策》。
